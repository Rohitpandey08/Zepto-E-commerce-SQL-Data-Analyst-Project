📌 Project Summary

This project is a real-world SQL data analysis case study built on an e-commerce inventory dataset scraped from Zepto, one of India’s leading quick-commerce platforms. The objective was to simulate how data analysts actually work in retail and e-commerce environments — starting from raw, messy data and ending with business-driven insights.

I designed this project to reflect end-to-end analyst workflows, not just query writing. That includes database setup, data exploration, cleaning inconsistencies, and answering practical business questions using SQL.

The dataset mirrors real catalog behavior: duplicate product names across different SKUs, varying weights and discounts, pricing stored in paise, inconsistent quantities, and stock availability flags. Each row represents a unique SKU rather than a unique product — exactly the kind of complexity analysts deal with in production systems.

Using PostgreSQL, I:

Created and structured the inventory database with appropriate data types and constraints

Performed EDA to understand categories, stock distribution, pricing patterns, and duplicates

Cleaned the data by removing invalid pricing records and standardizing currency values

Wrote business-focused SQL queries to analyze discounts, inventory weight, potential revenue, value-for-money products, and category-level performance

The analysis answers questions a real business would care about, such as:

Which categories carry the most inventory weight?

Which products offer the best value per gram?

Where is potential revenue being blocked due to stockouts?

Which categories provide the highest average discounts?

How pricing and weight impact perceived value for customers
